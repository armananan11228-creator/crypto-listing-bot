ساخت ربات تلگرام

۲ دقیقه
  1. در تلگرام جست‌وجو کن: @BotFather (تیک آبی دارد)
  2. دکمه‌ی Start را بزن
  3. بنویس: /newbot
  4. یک نام بده، مثلاً Arman Signals
  5. یک یوزرنیم بده که حتماً به bot ختم شود، مثلاً arman_spot_signals_bot
  6. BotFather یک توکن می‌دهد — کپی و جایی ذخیره‌اش کن
نمونه‌ی گفت‌وگو با BotFather — توکن در پیام آخر است
⚠️ این توکن مثل رمز عبور است. هیچ‌جا منتشرش نکن. اگر لو رفت با /revoke باطلش کن.
✅
نتیجه‌ی این قدم: یک رشته‌ی طولانی شبیه 7812345678:AAH9k...

گرفتن آی‌دی عددی چت

۱ دقیقه
  1. در تلگرام برو به @userinfobot
  2. Start را بزن — بلافاصله مشخصاتت را می‌فرستد
  3. عدد جلوی Id همان CHAT_ID توست
  4. حالا به رباتِ خودت (که در قدم ۱ ساختی) برو و یک بار Start بزن
    اگر این کار را نکنی، ربات اجازه ندارد به تو پیام بدهد
عدد Id را بردار — همین CHAT_ID است
✅
نتیجه: یک عدد ۹ تا ۱۰ رقمی مثل 146372819

بالا آوردن سرور وبهوک (رایگان)

۵ دقیقه

سرور باید یک آدرس HTTPS عمومی داشته باشد تا تریدینگ‌ویو بتواند به آن وصل شود. ساده‌ترین راه رایگان: Render.

  1. در render.com ثبت‌نام کن (با همان اکانت GitHub)
  2. New + → Web Service
  3. ریپوی crypto-listing-bot را انتخاب کن
  4. برنچ را بگذار: arena/01a0dd40-crypto-listing-bot
  5. تنظیمات:
    • Build Command: pip install -r requirements.txt
    • Start Command: gunicorn -w 2 -b 0.0.0.0:$PORT webhook_server:app
    • Instance Type: Free
  6. در بخش Environment Variables سه متغیر اضافه کن:
سه متغیر محیطی؛ WEBHOOK_SECRET را خودت یک رشته‌ی تصادفی بگذار
🌐 بعد از دیپلوی، Render یک آدرس می‌دهد مثل: https://crypto-listing-bot.onrender.com

برای تست، این آدرس را در مرورگر باز کن؛ باید صفحه‌ی وضعیت سبز با پیام «✅ متصل» ببینی.

✅
نتیجه: آدرس وبهوک تو → https://<آدرس-تو>/tradingview/<رمز>
۴

ساخت آلرت در تریدینگ‌ویو

۲ دقیقه
  1. اندیکاتور Spot Buy Scanner را روی چارت اضافه کن
  2. روی چارت راست‌کلیک → Add alert (در موبایل: آیکن ⏰)
  3. در کشوی Condition، اندیکاتور را انتخاب کن
  4. در کشوی دوم حتماً بزن: Any alert() function call
    این گزینه هر ۱۵ ارز را با یک آلرت پوشش می‌دهد
  5. Trigger: Once Per Bar Close
  6. تب Notifications → تیک Webhook URL و آدرس را بچسبان
پنجره‌ی Add alert — سه جای حیاتی علامت زده شده
⚠️ وبهوک از پلن Essential به بالا فعال است. روی پلن رایگان گزینه‌ی Webhook URL خاکستری می‌ماند.
۵

تست و دریافت پیام

۱ دقیقه

قبل از انتظار برای سیگنال واقعی، یک پیام آزمایشی بفرست:

curl -X POST https://<آدرس-تو>/test

باید بلافاصله در تلگرام چنین پیامی بیاید:

شکل نهایی پیام در تلگرام
✅ اگر این پیام رسید، همه‌چیز درست است. از این به بعد هر سیگنال خرید یا فروش خودکار می‌آید.

اگر پیام نیامد:

  • آدرس /health را باز کن — اگر configured: false بود، یعنی توکن یا چت‌آی‌دی ست نشده
  • مطمئن شو یک بار به ربات خودت Start زده‌ای
  • رمز انتهای آدرس دقیقاً برابر WEBHOOK_SECRET باشد
  • در صفحه‌ی اصلی سرور، تاریخچه‌ی ۳۰ آلرت آخر و دلیل رد شدنشان را می‌بینی
